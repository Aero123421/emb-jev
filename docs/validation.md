## 実モデルの確認

`examples/smoke.py`で次を確認しました。

| 入力 | Fixture | 共通バックボーンの実行回数 / 3質問 |
| --- | --- | --- |
| テキスト | 「カードから二重に代金が引き落とされた」 | 1 |
| 画像 | 224×224の単色赤画像 | 1 |
| 音声 | 16kHz mono、1秒の440Hz合成音 | 1 |
| 混合 | 説明文＋上記の画像＋音声 | 1 |

バックボーンにPyTorchのforward hookを付けて計測しました。
画像・音声エンコーダーの処理は、それぞれこのモデル内で追加されます。
候補登録時の処理回数はこの表に含みません。

全ケースで有限な類似度と合計1の相対重みを確認しました。
公式の`SentenceTransformer.encode()`とのEmbeddingのコサイン類似度は、
テキスト・画像・音声・混合の全てで0.99999以上でした。
入力上限を超える場合はforward前にエラーになること、文章と画像の見本候補を
同じタスクに登録できることも確認しました。

画像・音声は合成fixtureなので、実世界の分類精度を示す結果ではありません。
テキストの問い合わせ例は`billing`を選択しましたが、1例から精度は推定できません。

## 短文テキストの速度測定

再現コマンド:

```bash
HF_HOME="$PWD/.cache/huggingface" .venv/bin/python examples/benchmark.py \
  --text 'カードが二重請求された' --runs 10 --offline
```

| 項目 | 実測 |
| --- | --- |
| GPU | NVIDIA GeForce RTX 4070 |
| Python | 3.11.16 |
| モデル | テキストのみ、BF16、768次元 |
| モデルコミット | `914f7f89142e33e77833254d9c9b90c3cef7303b` |
| Sentence Transformers / Transformers | 6.1.0 / 5.19.0 |
| PyTorch | 2.14.1+cu130 |
| 入力 | 日本語11文字、Choice 1質問、3候補 |
| モデルロード＋候補準備 | 約4,206ms（ローカルにダウンロード済み） |
| ウォームアップ後の測定回数 | 10 |
| エンドツーエンド遅延 p50 | 約13.27ms |
| エンドツーエンド遅延 p95 | 約13.85ms |
| 測定中のモデルforward | 10回 |
| プロセスの最大RSS | 約1,822MiB |
| PyTorchのGPU最大割当 | 約527MiB |

エンドツーエンド遅延には前処理、forward、CPUへの結果転送、類似度計算を含めています。
RSSはモデルロードとウォームアップも含めたプロセス全体の最大値で、GPUメモリを含みません。
GPU割当はPyTorchの管理範囲の値で、GPUプロセス全体の使用量ではありません。

短文1種類・10回の初期測定です。長文、画像、音声、CPU、量子化モデルでの速度やメモリは
この数値から推定できません。分類精度、Booleanの否定・例外、Scoreの妥当性、
用途別の保留しきい値は、実データによる評価が残っています。
